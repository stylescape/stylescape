Django forms

Django renders forms without classes. Wrap them in <form class="ss-c-form"> and the form module styles that markup as it comes: field wrappers, labels, <div class="helptext">, <ul class="errorlist">, <ul class="errorlist nonfield">, aria-invalid widgets, required_css_class markers, and the fieldset Django uses for radio and checkbox groups. The selectors carry no specificity, so a class on a widget (attrs={"class": "ss-c-input"}) always wins. The markup below is Django 6 output, pasted unchanged. For hand-written templates the same look is available as classes (last example).

Unbound form

{{ form }} with required_css_class = "required": help text, a RadioSelect, a CheckboxSelectMultiple, a textarea and a BooleanField.
