Django templates

Jinja2 templates for Django and sturnus apps ship in src/templates/stylescape/ (outside this demo folder): a base page on the ss-l-app shell; list, detail, form and confirm-delete pages; macros for form fields, forms, formsets, pagination, breadcrumbs, tables, the page header and messages; and the auth pages. Usage

Add the package's template folder to the Jinja2 backend and extend a page:

Python 
# settings.py (the Jinja2 / sturnus.context.jinja2.Jinja2 backend)
TEMPLATES[0]["DIRS"] = [BASE_DIR / "node_modules" / "stylescape" / "src" / "templates"]

{# projects/templates/projects/project_list.html.jinja #}
{% extends "stylescape/pages/list.html.jinja" %}
{% block title %}{{ _("Projects") }}{% endblock %}
